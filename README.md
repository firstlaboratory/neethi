# Neethi — Indian law, simply

Offline web app for reading Indian laws in plain English: the Constitution, BNS/BNSS/BSA (with old IPC/CrPC/Evidence Act lookup), consumer, motor vehicle, RTI, IT, family and Tamil Nadu laws.

Live: https://firstlaboratory.github.io/neethi/

Summaries are for understanding only, not legal advice. Check the official text on India Code before relying on any section.
